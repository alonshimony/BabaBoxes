# Baba Boxes Reveal

Interactive investor film for the Baba Boxes launch by Baba Entertainment.

A static site with no build step: `index.html` plus two videos and three images. Deploy the repository root as-is (for example on Vercel with the "Other" framework preset and no build command).

## Files

| File | Purpose |
|---|---|
| `index.html` | The film: 14 scenes, presenter controls, phone layouts |
| `baba-box-teaser.mp4`, `teaser-poster.jpg` | Opening BABA BOX teaser (scene 1) |
| `box-demo.mp4`, `demo-poster.jpg` | Live box-opening demo (scene 4) |
| `lobby.jpg` | Baba Boxes lobby screenshot (scene 3) |

## Controls

Next / Prev buttons, arrow keys or space, or tap the film (left side goes back). On phones, turn the device sideways for full screen.

Projections shown in the film are forward-looking and unaudited. Confidential.
